# Instructions Claude Code

## Règles générales

- Travaille uniquement dans le projet actuel.
- Lis uniquement les fichiers nécessaires à la tâche.
- Ne modifie pas les fichiers qui ne sont pas concernés.
- Ne crée pas de nouvelles dépendances sans me demander.
- Réutilise les composants et fonctions existants avant d'en créer de nouveaux.
- Ne réécris pas un fichier entier lorsqu'une modification ciblée suffit.
- Ne supprime aucune fonctionnalité existante sans confirmation.
- Ne modifie jamais les secrets, clés API ou fichiers `.env`.
- Après une modification, vérifie uniquement ce qui est nécessaire.
- Si quelque chose est ambigu, demande avant de faire une modification importante.

## Communication

- Réponds brièvement.
- Explique ce que tu as modifié.
- Indique les fichiers modifiés.
- N'explique pas chaque ligne de code sauf si je le demande.

## Développement

Avant de modifier du code :
1. Identifie les fichiers concernés.
2. Lis uniquement les parties nécessaires.
3. Vérifie les composants ou fonctions existants pouvant être réutilisés.
4. Effectue la modification minimale.
5. Vérifie que le projet fonctionne.

## Dépendances

Ne lance pas `npm install`, `npm uninstall` ou l'ajout d'une nouvelle dépendance sans mon accord explicite.
